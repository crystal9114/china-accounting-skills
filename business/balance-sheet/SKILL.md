# 资产负债表生成

## 使用前必读

根据企业实际情况选择对应版本：

> **快速判断**（依据《小企业会计准则》财会〔2011〕17号第二、三条）：股票或债券公开交易 / 金融机构 / 企业集团内母子公司 / 大中型企业 → **企业准则版**（完整资产负债表，含递延税/商誉/使用权资产/投资性房地产等）。其余符合划型标准的小型企业 → **小企业版**。**增值税一般纳税人不等于企业准则**。详见 `accounting-framework` 获取完整判断流程。

填列要点（均出自上述附录的编制说明）：

- "无形资产"项目直接填列账面价值（无形资产减累计摊销后的净额），官方格式没有"累计摊销"单独行；"固定资产"则分列原价、累计折旧、账面价值。
- "预付账款"期末为贷方余额的，在"应付账款"列示；"应收账款"期末为贷方余额的，在"预收账款"列示；超过1年期的预付账款借方余额在"其他非流动资产"列示。
- "其他流动资产"含1年内到期的非流动资产；"其他流动负债"含1年内到期的非流动负债（所以小企业表上没有单独的"一年内到期的非流动负债"行）。
- "存货"包含材料采购、在途物资、原材料、材料成本差异、生产成本、库存商品、商品进销差价、委托加工物资、周转材料、消耗性生物资产等科目的余额。

## 企业准则版关键新增科目

| 新增科目 | 含义 | 何时出现 |
|---------|------|---------|
| **交易性金融资产** | 短期持有的股票/债券/理财产品 | 公司有闲置资金理财 |
| **合同资产** | 已履约但收款还取决于其他条件 | 工程公司按履约进度确认收入 |
| **使用权资产** | 租赁期内可使用租赁资产的权利 | 租了办公室或设备（新租赁准则） |
| **投资性房地产** | 为赚租金或资本增值持有的房产 | 公司名下有出租的房产 |
| **商誉** | 收购溢价（合并价差） | 公司历史上收购过其他企业 |
| **递延所得税资产/负债** | 会计和税法的时间差 | 任何有计提减值准备或有税法折旧差的企业 |
| **债权投资/其他债权投资** | 持有的债券（分两类） | 公司持有外部债券 |
| **其他权益工具投资** | 战略持有的非交易性股票 | 公司参股了其他企业但不用权益法 |
| **合同负债** | 预收的款项（新收入准则称谓） | 预收客户货款 |
| **租赁负债** | 未来应支付的租赁付款额现值 | 新租赁准则下的长期租赁 |
| **预计负债** | 未决诉讼/保修义务等 | 有未决诉讼或售后保修责任 |
| **其他综合收益** | 未进利润的浮动盈亏 | 其他债权投资的公允价值变动 |
| **少数股东权益** | 非100%控股子公司的外部权益 | 有非全资子公司 |

# 两版通用：平衡检验

```
⚖ 会计等式平衡检验
═══════════════════════════════════
资产总计              =  XXX,XXX.XX
负债合计              =   XX,XXX.XX
所有者权益合计        =  XXX,XXX.XX
───────────────────────────────────
负债 + 所有者权益     =  XXX,XXX.XX
差异                  =        0.00

结果：✓ 平衡 — 资产 = 负债 + 所有者权益
```

如果不平衡：

```
结果：✗ 不平衡 — 差异 = X,XXX.XX

按以下顺序排查：
1. 所有一级科目期初/期末余额是否正确
2. 本期所有记账凭证的借贷是否平衡
3. 月末结转分录是否完整（收入/成本费用→本年利润）
4. 涉及其他综合收益的科目是否遗漏
5. 合并层面是否有少数股东权益遗漏
6. 差异如果是整数 → 检查是否有漏记或重记的凭证
```

## 常规重分类调整

| 报表项目 | 来源 | 重分类至 |
|---------|------|---------|
| 应收账款（贷方余额） | 账面贷方 | 小企业：**预收账款**；企业准则：**预收款项** 或 **合同负债** |
| 应付账款（借方余额） | 账面借方 | **预付账款** |
| 其他应收款（贷方余额） | 账面贷方 | **其他应付款** |
| 长期借款（一年内到期） | 长期借款 | 企业准则：**一年内到期的非流动负债**；小企业：**其他流动负债**（附录编制说明） |
| 长期应付款（一年内到期） | 长期应付款 | 企业准则：**一年内到期的非流动负债**；小企业：**其他流动负债** |

## 企业准则重点分析指标

| 指标 | 计算 | 说明 |
|------|------|------|
| 资产负债率 | 负债/资产 | >70% → 银行可能警惕；<40% → 杠杆利用不足 |
| 流动比率 | 流动资产/流动负债 | <1.5 → 短期偿债压力大 |
| 产权比率 | 负债/所有者权益 | 反映债权人和股东的投入比例 |
| 商誉占比 | 商誉/净资产 | >30% → 商誉减值风险高 |
| 递延所得税资产/利润 | 比率 | 持续高企 → 利润质量可能有问题 |

## 重要提示

- 企业准则允许**选择性使用公允价值**计量部分资产（投资性房地产等），一经选择不得随意变更
- 商誉**不再摊销**，但每年至少进行一次**减值测试**（减值损失不可转回）
- 新租赁准则下，几乎所有经营租赁都要在表内确认使用权资产和租赁负债（一年以内或低价值除外）
- 递延所得税是**时间性差异**，最终会在未来转回→如果企业持续亏损，递延所得税资产需要评估可收回性
