# 会计准则选择指南

## 概述
中国目前有两套并行会计准则体系。选错准则 = 从科目到报表全盘错误。本技能根据企业实际规模帮你判断应该用哪套。

## 判断决策树

> 依据：《小企业会计准则》（财会〔2011〕17号）第二条、第三条；《中小企业划型标准规定》（工信部联企业〔2011〕300号）。
> 原文：https://kjs.mof.gov.cn/zhengcefabu/201111/t20111107_605525.htm（财政部会计司，附件为准则全文PDF）
> **增值税纳税人身份（小规模/一般纳税人）与会计准则选择无关**，不能用"一般纳税人"或"年销售额500万"来判断准则（500万是增值税法第九条的小规模纳税人标准，不是会计准则标准）。

```
企业是否属于以下任一情形？（准则第二条，三类不能执行小企业会计准则）
├── 股票或债券在市场上公开交易
├── 金融机构或其他具有金融性质的企业
└── 企业集团内的母公司或子公司
       │
       ├── 是 → 【企业会计准则】
       │
       └── 否 → 是否符合《中小企业划型标准规定》的小型企业标准？
               │
               ├── 是 → 【小企业会计准则】或自愿选择【企业会计准则】（准则第三条）
               └── 否（属大中型企业）→ 【企业会计准则】
```

## 划型标准（工信部联企业〔2011〕300号，与行业有关）

以批发业（贸易企业通常归此类）为例，原文：

| 类型 | 条件 |
|------|------|
| 中型 | 从业人员 20人及以上，且营业收入 5000万元及以上 |
| 小型 | 从业人员 5人及以上，且营业收入 1000万元及以上 |
| 微型 | 从业人员 5人以下，或营业收入 1000万元以下 |
| 中小微型（合计） | 从业人员 200人以下，或营业收入 40000万元以下；不满足此条件的为大型 |

零售业、制造业（工业）等其他行业阈值不同，须按所属行业查原文：https://www.miit.gov.cn/jgsj/qyj/wjfb/art/2011/art_235af1ade45c4865957adeed23f9d949.html

## 两套准则的适用场景

| 场景 | 适用准则 | 依据 |
|------|---------|------|
| 符合划型标准的小型企业，非上述三类除外情形 | 小企业会计准则（也可自愿选企业会计准则） | 准则第二、三条 |
| 小企业公开发行股票或债券 | 必须转为企业会计准则 | 准则第三条（三） |
| 因规模或性质变化成为大中型企业或金融企业 | 从次年1月1日起转为企业会计准则 | 准则第三条（三） |
| 有多家子公司或关联公司（企业集团内的母公司、子公司） | 企业会计准则 | 准则第二条（三） |
| 上市公司、大中型企业 | 企业会计准则，不得转为小企业会计准则 | 准则第三条（四） |

> 实务考量（非官方规定）：有银行融资、引入投资人、计划上市的企业，对方往往习惯看企业准则报表，可自愿选企业准则，但选了不能转回。

## 两套准则核心差异速查

| 维度 | 小企业会计准则 | 企业会计准则 |
|------|--------------|-------------|
| **科目数量** | 66（财会〔2011〕17号附录会计科目表，已核对） | 以财政部公布的科目表为准（财会〔2006〕18号附录及后续修订） |
| **资产减值** | 不计提 | 计提（坏账/存货跌价/固定资产减值等） |
| **坏账处理** | 直接转销→营业外支出 | 备抵法→信用减值损失 |
| **金融资产** | 成本模式 | 三类（摊余成本/FVOCI/FVTPL） |
| **长期股权投资** | 统一成本法 | 成本法/权益法 |
| **债券折溢价** | 直线法 | 实际利率法 |
| **所得税** | 应付税款法 | **资产负债表债务法**（递延所得税） |
| **会计政策/估计变更、差错更正** | 一律未来适用法（准则第八十八条） | 政策变更和重要前期差错追溯调整（企业会计准则第28号） |
| **融资租赁** | 付款总额入账 | 使用权资产+租赁负债 |
| **资本公积** | 仅资本溢价 | 资本溢价+其他资本公积 |
| **财务报表** | 资产负债表、利润表、现金流量表和附注（准则第七十九条） | 另含所有者权益变动表 |
| **合并报表** | 不涉及 | 母公司需编制 |

## 转换规则

- 已执行企业会计准则的企业 → **不能转回**小企业会计准则（准则第三条（四），财会〔2011〕17号）
- 现在用小企业准则的企业 → 可以**自愿转为**企业会计准则
- 转换时的会计处理：按《企业会计准则第38号——首次执行企业会计准则》等规定（准则第四条）
- 执行企业会计准则的小企业，不得同时选择执行小企业会计准则的相关规定（准则第三条（二））；执行小企业准则遇到准则未规范的交易，可参照企业会计准则处理（准则第三条（一））
- 动态提醒：财政部2026年7月印发修订后的《企业会计准则第30号——财务报表列报》（财会〔2026〕11号），非上市企业自2030年1月1日起执行，鼓励提前执行；执行小企业会计准则的企业目前不受影响。同时，财政部2026年9月30日就《企业会计准则——会计科目和主要账务处理》修订发布征求意见稿（财办会〔2026〕35号，尚未生效）。

## 本技能包中的对应关系

不同技能内部标注了两种准则的版本：

| Skill | 小企业版 | 企业准则版 |
|-------|---------|-----------|
| `chart-of-accounts` | 66 科目 | 以财政部公布的企业准则科目表为准 |
| `journal-entry` | 通用（注意小企业无准备金科目） | 通用 |
| `profit-loss` | 简化利润表 | 完整利润表（+资产减值/信用减值/公允价值变动） |
| `balance-sheet` | 简化资产负债表 | 完整资产负债表（+递延税/投资性房地产等） |
| `cn-corporate-tax`（已装，企业所得税） | 应付税款法 | 资产负债表债务法 |
| `month-end-close` | 简化结账 | 完整结账（+减值测试等） |
| `cn-vat`（已装，增值税） | 通用（按纳税人类型区分） | 通用（按纳税人类型区分） |

## 判断输出

使用本技能时，先输出判断结论：

```
📋 会计准则选择判断
════════════════════════════════════

企业基本信息：
  年收入规模：________ 元
  从业人数：__________ 人
  资产总额：__________ 元
  增值税纳税人类型：□ 小规模纳税人 □ 一般纳税人
  是否涉及公开市场：□ 是 □ 否
  是否有外部融资需求：□ 是 □ 否

────────────────────────────────────
判断结论：适用【小企业会计准则】
理由：非上市、非金融机构、非企业集团内母子公司，且符合划型标准的小型企业

后续所有记账理账请使用【小企业会计准则】版本。
════════════════════════════════════
```

> 如果不确定，按上面的决策树逐条核对：能执行小企业会计准则的，可以执行，也可以自愿选企业会计准则；一旦选了企业会计准则就不能转回。纳税人身份（一般/小规模）不影响判断。
