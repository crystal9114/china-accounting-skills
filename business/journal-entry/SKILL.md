# 记账凭证编制

## 概述
按照《会计基础工作规范》（财政部令第98号，2019年修改，第五十一条）和《小企业会计准则》（财会〔2011〕17号）要求，编制标准格式的记账凭证。增值税相关分录依据《增值税会计处理规定》（财会〔2016〕22号，对两套准则均适用）。自动检查借贷平衡，确保凭证符合归档和审计追溯要求。

## 记账凭证必备要素

每张凭证必须包含以下要素（《会计基础工作规范》第五十一条列明 7 项）：

| 要素 | 说明 |
|------|------|
| ① 填制日期 | 填制凭证的日期 |
| ② 凭证编号 | 连续编号（现收/银收/现付/银付/转 分类或统一编号）；一笔业务需两张以上凭证时可用分数编号法 |
| ③ 经济业务摘要 | 简明扼要，谁+做了什么+金额——例如"销售A商品给XX公司" |
| ④ 会计科目 | 总账科目 + 明细科目（参照 `chart-of-accounts` 科目表） |
| ⑤ 金额 | 借/贷金额，借贷合计必须相等 |
| ⑥ 附件张数 | 所附原始凭证张数（发票、合同、银行回单、出库单等） |
| ⑦ 签章栏 | 填制、稽核、记账人员和会计机构负责人（会计主管人员）签名或盖章；收款、付款凭证还须出纳人员签名或盖章 |

> 记账标记（过账标记）是账务处理习惯，不在第五十一条要素之列，可保留。

## 编制流程

1. **接收业务信息**：获取业务日期、业务内容、涉及的科目和金额
2. **验证科目**：从 `chart-of-accounts` 确认科目编码和名称正确
3. **确认借贷方向**：
   - 资产、成本、费用增加 → 借方
   - 负债、所有者权益、收入增加 → 贷方
   - 反向业务 → 相反方向
4. **写出分录**：每笔分录一行，一个借方对应一个贷方（可一借多贷或多借一贷）
5. **自动验证借贷平衡**：借方合计 = 贷方合计（差异不得>0.01元）
6. **输出标准格式凭证**
7. **标注附件**：列出应附的原始凭证类型

## 标准凭证格式

输出时应使用以下格式：

```
                    记 账 凭 证
                    2026年 5月10日                   转字第001号

┌────────────┬────────────────┬────────────┬────────────┬────────────┐
│   摘  要   │   总账科目     │  明细科目  │  借方金额  │  贷方金额  │
├────────────┼────────────────┼────────────┼────────────┼────────────┤
│ 销售A商品  │ 银行存款       │ 工商银行   │  10,100.00 │            │
│ 给XX公司   │ 主营业务收入   │ A商品收入  │            │  10,000.00 │
│            │ 应交税费       │ 应交增值税 │            │     100.00 │
├────────────┴────────────────┴────────────┼────────────┼────────────┤
│              合  计                      │  10,100.00 │  10,100.00 │
└──────────────────────────────────────────┴────────────┴────────────┘

借贷平衡验证：✓ 借方 10,100.00 = 贷方 10,100.00

附件：增值税普通发票1张、银行回单1张、出库单1张 共3张

会计主管：______  记账：______  审核：______  制单：______
```

## 核心分录模板

### 销售商品（一般纳税人，增值税法第十条：销售货物税率 13%）

```
借：银行存款（或应收账款）     （含税金额）
  贷：主营业务收入           （不含税金额）
      应交税费 — 应交增值税（销项税额）   （不含税金额 × 13%）
```

> 一般纳税人"应交增值税"明细科目设"销项税额""进项税额"等专栏（财会〔2016〕22号）。铝锭、铝制品等一般货物适用13%；个别货物适用9%，以增值税法第十条为准（《中华人民共和国增值税法》，主席令第四十一号，2026年1月1日起施行）。
> 会计上已确认收入、但增值税纳税义务尚未发生（增值税法第二十八条：收讫销售款项或取得索取销售款项凭据的当日，先开具发票的为开票当日）的，销项税额先记"应交税费 — 待转销项税额"，纳税义务发生时再转入"应交增值税（销项税额）"（财会〔2016〕22号）。

### 销售商品（小规模纳税人，征收率 3% 减按 1%）

```
借：银行存款（或应收账款）
  贷：主营业务收入           （不含税金额）
      应交税费 — 应交增值税   （不含税金额 × 1%）
```

> 小规模纳税人销售货物等应税交易（不含销售、出租不动产、转让土地使用权），3%征收率减按1%，执行期2026年1月1日至2027年12月31日（财政部 税务总局公告2026年第10号，承接公告2023年第19号）：https://szs.mof.gov.cn/zhengcefabu/202601/t20260131_3983036.htm 。小规模纳税人只设"应交增值税"明细科目，无专栏。

### 采购商品（小规模纳税人，税款计入成本，增值税法第二十二条：简易计税项目对应的进项税额不得抵扣）

```
借：库存商品（或原材料）     （含税金额）
  贷：银行存款（或应付账款）
```

### 采购商品（一般纳税人，价税分离）

```
借：库存商品                  （不含税金额）
    应交税费 — 应交增值税（进项税额）
  贷：银行存款                 （含税金额）
```

> 小企业购进商品的运输费、装卸费、包装费、保险费、合理损耗、入库前挑选整理费等进货费用，商品流通企业计入"销售费用"（见 `chart-of-accounts` 5601 说明）。进项税额须取得增值税法实施条例第十一条列明的扣税凭证（增值税专用发票、海关进口增值税专用缴款书、农产品收购发票等）并确认用途后方可抵扣。

### 支付员工工资

```
借：应付职工薪酬              （应发金额）
  贷：银行存款                 （实发金额）
      应交税费 — 应交个人所得税
      其他应付款 — 社保（个人部分）
      其他应付款 — 公积金（个人部分）
```

### 计提本月折旧

```
借：管理费用 — 折旧费（或制造费用 — 折旧费）
  贷：累计折旧
```

### 计提企业所得税（小企业，应付税款法）

```
借：所得税费用
  贷：应交税费 — 应交企业所得税
```

> 小企业所得税费用按当期应交所得税确认，不做递延所得税（准则第七十一条）。企业所得税按季预缴。
> 小型微利企业（国家非限制和禁止行业，年应纳税所得额不超过300万元、从业人数不超过300人、资产总额不超过5000万元）：减按25%计入应纳税所得额、按20%税率缴纳，实际税负5%，延续执行至2027年12月31日（财政部 税务总局公告2023年第12号第三条、第五条）：https://fgk.chinatax.gov.cn/zcfgk/c102416/c5210453/content.html

### 计提增值税附加税及相关税费（六税两费减半）

```
借：税金及附加
  贷：应交税费 — 应交城市维护建设税
      应交税费 — 应交教育费附加
      应交税费 — 应交地方教育附加
```

> 增值税小规模纳税人、小型微利企业、个体工商户，对资源税（不含水资源税）、城市维护建设税、房产税、城镇土地使用税、印花税（不含证券交易印花税）、耕地占用税和教育费附加、地方教育附加，减按50%征收，2023年1月1日至2027年12月31日（财政部 税务总局公告2023年第12号第二条、第四条）。**小型微利企业也适用，不限于小规模纳税人。** 新设立的一般纳税人，首次汇算清缴前，可按公告第五条规定的月末条件先享受。
> 房产税、城镇土地使用税、车船税、印花税计入"税金及附加"（财会〔2016〕22号）。

### 月末结转收入

```
借：主营业务收入
    其他业务收入
    营业外收入
  贷：本年利润
```

### 月末结转成本费用

```
借：本年利润
  贷：主营业务成本
      其他业务成本
      税金及附加
      销售费用
      管理费用
      财务费用
      营业外支出
      所得税费用
```

## 验证规则

- [ ] 借贷金额合计相等（差异 = 0）；上文步骤5里"差异不得>0.01元"的容差说法作废，借贷必须完全相等
- [ ] 所有科目编码在科目表中存在
- [ ] 每笔分录有明确的摘要
- [ ] 附件张数已标注
- [ ] 不得将不同内容和类别的原始凭证汇总填制在一张记账凭证上（《会计基础工作规范》第五十一条）
- [ ] 更正错误时使用红字冲销法或补充登记法，不得涂改

## 重要提示

- 凭证编号应按月连续，不能跳号或重号
- 小规模纳税人的采购增值税**全部计入采购成本**，不得抵扣
- 一般纳税人取得增值税专用发票（含数电专票）等扣税凭证，申报抵扣前须在增值税发票综合服务平台/税务数字账户勾选确认用途；认证已取消，改为勾选确认（国家税务总局公告2019年第45号，部分条款后已修订，以现行版本为准）
- 来自外部的电子发票（含数电票）与纸质凭证具有同等法律效力；同时满足四项条件（凭证经查验合法真实；传输存储安全可靠，篡改可被及时发现；会计核算系统能准确读取并防止重复入账；归档符合《会计档案管理办法》）时，可仅以电子形式入账归档，不必另打印纸质件；若以打印件入账，必须同时保存电子原件（财会〔2020〕6号《关于规范电子会计凭证报销入账归档的通知》）：https://www.gov.cn/zhengce/zhengceku/2020-04/03/content_5498598.htm
