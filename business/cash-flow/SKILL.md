# 现金流量表生成

## 概述
生成符合《小企业会计准则》的现金流量表。现金流量表反映企业在一定期间内现金的流入和流出，帮助判断企业的支付能力和资金周转情况。

> 依据：财会〔2011〕17号《小企业会计准则》第八十二条及附录"会小企03表"（月报、年报）。小企业准则里的"现金"是指库存现金以及可以随时用于支付的存款，**没有"现金等价物"概念**（那是企业会计准则第31号的口径）。原文：https://kjs.mof.gov.cn/zhengcefabu/201111/P020111118325852734144.pdf 第78-81页。

## 生成流程

1. **确认报告期间**：通常是月份、季度或年度
2. **获取期初现金余额**：从上一期资产负债表"货币资金"期初数
3. **分类现金流**：

   **经营活动现金流** — 与主营业务直接相关的收支：
   - 流入：销售收款、提供劳务收款、收到的税费返还、政府补贴（稳岗补贴等）
   - 流出：采购付款、工资发放、税费缴纳、房租水电、差旅、办公费等

   **投资活动现金流** — 与长期资产购建和对外投资相关的收支：
   - 流入：收回投资本金、收到股息/利息、处置固定资产收款
   - 流出：购买固定资产、在建工程、无形资产、对外投资

   **筹资活动现金流** — 与资本和债务相关的收支：
   - 流入：股东增资、取得银行借款
   - 流出：偿还借款本金、支付利息、向股东分红

4. **现金净增加额 = 经营活动净额 + 投资活动净额 + 筹资活动净额**
5. **期末现金余额 = 期初现金余额 + 现金净增加额**（"现金"限于库存现金和可随时用于支付的存款；核对资产负债表期末"货币资金"时，如其中含不能随时支付的款项，如保证金存款、受限存款，应先剔除）

## 编制方法

现金流量表不是直接从科目余额取数，而是需要**按收付实现制重新分类**：

- 收入类科目（如应收账款回收）→ 经营活动现金流入
- 费用类科目 → 经营活动现金流出（但要区分哪些是本期实际支付的）
- 固定资产、无形资产购置 → 投资活动现金流出
- 借款、还款 → 筹资活动现金流入/流出

**关键勾稽关系**：
- 期末现金余额 = 资产负债表"货币资金"期末余额，扣除其中不能随时用于支付的部分 ✓
- 经营活动现金流入 ≈ 营业收入 + 应收账款减少 + 预收账款增加
- 支付的税费 ≈ 应交税费期初 + 本期计提 - 应交税费期末

## 分析输出示例

```
💵 现金流分析摘要
═══════════════════════════════════
经营活动现金净额：    +80,000  ✓ 为正，主业造血能力良好
投资活动现金净额：    -30,000     正常投资扩张
筹资活动现金净额：    +10,000     新增借款
───────────────────────────────────
现金净增加额：        +60,000
期初现金余额：        +40,000
期末现金余额：       +100,000  = 资产负债表货币资金 100,000 ✓
═══════════════════════════════════

📊 现金流健康评估：
• 经营活动净额 > 0 ✓ — 主营业务持续产生正向现金流
• 经营净额 > 净利润？若否，可能存在大量应收账款未回收
• 期末现金/月均支出 ≈ 3.2 个月 — 安全垫充足
```

## 重要提示

- 小企业现金流量表中的"现金"是库存现金以及可以随时用于支付的存款（准则第八十二条）；其他货币资金中的银行汇票存款、信用证保证金存款等，是否属于"可随时用于支付"要看具体款项性质
- 支付宝/微信等第三方支付平台余额：附录对"其他货币资金"的列举（银行汇票存款、银行本票存款、信用卡存款、信用证保证金存款、外埠存款、备用金）里没有，官方无明文，实务按其他货币资金设明细核算，能随时支付的计入现金
- 定期存款不能随时用于支付的，不符合"现金"定义；附录未对此情形单列处理规则。原稿"≥3个月定期存款属投资活动"的说法，在小企业准则及附录里找不到出处，已删除，遇到时按现金定义判断并在附注说明
- 附录给出的现金流量表格式为直接法项目，原稿"不需要列示间接法"的表述无出处，已删除
